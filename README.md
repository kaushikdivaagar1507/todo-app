# 📝 MERN ToDo App

A full-stack ToDo application built using the MERN stack.

## 🚀 Features

- ✅ Add Tasks
- ✏️ Edit Tasks
- 🗑️ Delete Tasks
- ☑️ Mark Tasks as Completed
- 💾 MongoDB Atlas Database
- 🔄 REST API
- ⚡ React + Vite Frontend

## 🛠️ Tech Stack

Frontend:
- React
- Vite
- Axios
- CSS

Backend:
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
